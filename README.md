# 🔐 Cofre Portátil

Armazenador de senhas portátil, seguro e offline. Não precisa instalar, não usa nuvem.

### ✨ Funcionalidades
- Criptografia AES-256 para proteger seus dados
- Arquivo `.dat` criado junto do executável
- Acesso com Master Key
- 100% offline e portátil

### 📥 Como usar (usuário final)
1. Vá em `Releases` aqui do GitHub
2. Baixe o arquivo `.exe` mais recente
3. Execute e crie sua Master Key
